# 實驗紀錄表（複製填寫範本）

依據：[一頁式試驗規格](trial-spec-template.md)｜[handoff第六十一節](../../handoff.md#impact-metrics-data-acceptance-calibration-20261023)。本表供複製填寫，不是實測資料，也不解除硬體暫停或授權裝置操作。

填寫規則：未知、未測、未核實的值與結論一律填「待確認」，不可用0、未發生或NA代替。不適用或無法定量時，須同列原因與證據。原始輸出中的NA原樣保存，表單另記其含義；不改寫原始檔。所有品質計數、狀態、同意與有效性均待確認後才填。

本表新增的全域ID、事件邊界、試片履歷及有效性等為「手動追溯」，不代表韌體已自動產生。依序填A、B，按C說明建立各量測鏈紀錄；每片每次試驗複製D與E；最後填F。
